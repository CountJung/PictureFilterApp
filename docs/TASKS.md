- [ ] **PF-028 · 전용 사진 촬영 화면과 카메라 제어 구현**

  **상태: 보류** · 우선순위: P0

  - **할 일:** AVFoundation 촬영 세션·미리보기·사진 출력을 별도 서비스로 만들고 전후면 전환, 탭 초점, 노출 조절, 지원되는 플래시와 셔터를 연결합니다. 권한 거부·복구, 백그라운드·통화 등 세션 중단, 연속 셔터 입력과 촬영 실패를 처리합니다.
  - **완료 조건:** 실기기에서 전후면 촬영 데이터가 편집기로 전달됨. 권한·세션 중단 후 복구와 취소 가능. 불필요한 중간 JPEG 재압축 없이 캡처 데이터 보관. 시뮬레이터는 대역 또는 미지원 안내.
  - **구현 / 자동 검증:** 전용 촬영 화면·AVFoundation 직렬 세션·전후면·초점·노출·지원 플래시·원본 데이터 전달·중단/취소/실패 복구를 구현했습니다. 시뮬레이터 최종 58개 테스트와 기기용 무서명 빌드 통과. [PF-028 검증 기록](E2E.md#pf-028).
  - **남은 조건:** 실제 iPhone이 연결 불가 상태이므로 실기기 촬영·권한·초점·플래시·인터럽트·화각/방향을 아직 검증하지 않았습니다. E2E의 PF-028-V01~V05를 실행한 뒤 완료 처리합니다.
  - **선행 작업:** 없음 — 기존 시스템 카메라 연결 대체
  - **설계 / 검증:** [MASTER_PLAN](MASTER_PLAN.md), [ARCHITECTURE](ARCHITECTURE.md#portrait-camera-next), [E2E](E2E.md#portrait-camera-acceptance)

- [ ] **PF-029 · 기기 지원 배율 탐색·연속 줌·렌즈 전환 구현**

  **상태: 보류** · 우선순위: P0

  - **할 일:** 현재 활성 장치·포맷의 허용 최소/최대 줌과 가상 카메라 전환 지점을 읽어 배율 버튼·핀치·슬라이더를 구성합니다. 실제 장치 줌과 사용자 표시 배율을 구분하며 지원 OS API에 가용성 분기를 둡니다. 디지털 확대와 렌즈 전환을 구분하고 전후면·포맷 변경 시 범위와 현재값을 다시 맞춥니다.
  - **완료 조건:** 지원 배율만 표시하고 연속 조절은 현재 허용 범위를 넘지 않음. 최소·최대·중간값·렌즈 경계에서 미리보기와 촬영 화각 일치. 전후면 전환 후 잘못된 배율 미유지. 단일/복수 카메라 대역 및 보유 실기기 검증; 미보유 기종은 미검증으로 표시.
  - **구현:** 장치/포맷 허용 줌·표시 배율·렌즈 경계 탐색, 복수 렌즈 우선 선택, 버튼·슬라이더·핀치, 최신 입력 병합, 전후면 초기화 및 포맷 변경 관찰 구현. 모델 15개+UI 1개 통과 및 기기용 무서명 빌드 성공. [검증 기록](E2E.md#pf-029).
  - **남은 수용:** 실제 렌즈 전환·미리보기/촬영 화각·보유 기기별 배율 확인은 실기기 없이 검증할 수 없어 미검증으로 유지.
  - **선행 작업:** PF-028
  - **설계 / 검증:** [MASTER_PLAN](MASTER_PLAN.md), [ARCHITECTURE](ARCHITECTURE.md#portrait-camera-next), [E2E](E2E.md#portrait-camera-acceptance)

- [ ] **PF-030 · 촬영 중심 진입과 촬영 후 필터·재촬영 흐름 통합**

  **상태: 보류** · 우선순위: P0

  - **할 일:** 시작 화면에서 바로 촬영·사진 선택으로 진입하도록 샘플 중심 구조를 바꿉니다. 촬영 직후 화사한 필터 선택·강도 조절·원본 비교·저장을 연결하고 재촬영 때 선택 프리셋 유지 정책을 구현합니다. 사진별 얼굴 보정값은 새 사진에 잘못 이월되지 않게 합니다.
  - **완료 조건:** 샘플 선택 없이 시작 → 배율 조절 → 촬영 → 화사한 필터 → 비교 → 저장 왕복 성공. 취소·재촬영·사진 교체에서 이전 사진/설정이 덮이지 않음. 전면 미러링·회전 방향·미리보기와 저장 구도 확인.
  - **구현:** 시작 화면 촬영·사진 선택 직접 진입, 첫 촬영 화사한 인물 기본 선택, 재촬영 필터·강도·밝기·따뜻함 유지와 사진별 보정 초기화. 잘못된 촬영·사진 교체 입력은 기존 사진/편집 보존. 단위 62개+UI 4개 통과. [검증 기록](E2E.md#pf-030).
  - **남은 수용:** 실제 전면 미러링·회전·저장 구도는 PF-028/PF-029와 함께 실기기 미검증으로 유지.
  - **선행 작업:** PF-027·PF-028·PF-029
  - **설계 / 검증:** [MASTER_PLAN](MASTER_PLAN.md), [ARCHITECTURE](ARCHITECTURE.md#portrait-camera-next), [E2E](E2E.md#portrait-camera-acceptance)

- [ ] **PF-032 · 피부·머리카락 경계 및 출력 크기별 효과 일관성 개선**

  **상태: 보류** · 우선순위: P1

  - **할 일:** 피부 마스크의 눈·입 보호 영역이 경계 완화 후 침범되는지 확인하고 가림·옆얼굴·모발 경계를 개선합니다. 배경 흐림의 전경색 번짐을 줄이고, 얼굴 분석 대상과 마스크가 미리보기/출력 해상도에서 동일하게 대응하도록 합니다. 배경 흐림의 고정 48px 상한에 따른 상대 강도 차이를 교정합니다.
  - **완료 조건:** 동일 사진의 1600px 미리보기와 4096px 출력을 같은 화면 크기로 비교해 인물 대상·조명 범위·흐림 강도 일치. 눈/입/머리카락·전경 경계 확대 리뷰와 가림·다중 인물 사례 검증.
  - **구현:** 페더링 뒤 눈/입/윤곽 보호 마스크 재적용, 겹친 인물의 보호 영역 덮임 방지, 배경 전용 정규화 흐림으로 전경색 번짐 억제. 1600px 공통 작업 해상도에서 흐림을 계산하고 출력 크기로 확대하여 상대 강도 유지. PF-033의 공통 분석 좌표 재사용과 결합.
  - **남은 수용:** 가림·옆얼굴·모발·다중 인물의 실제 사진 확대 리뷰와 사용자 품질 판정은 미검증. 자동 경계/크기 검증 포함 단위 68개, macOS 보조 검사 및 기기용 무서명 빌드 통과. [검증 기록](E2E.md#pf-032).
  - **선행 작업:** PF-026·PF-027·PF-031 평가 결과
  - **설계 / 검증:** [MASTER_PLAN](MASTER_PLAN.md), [ARCHITECTURE](ARCHITECTURE.md#portrait-camera-next), [E2E](E2E.md#portrait-camera-acceptance)
  - **담당 / 갱신일:** Codex / 2026-10-02

- [ ] **PF-033 · 인물 분석 상태 안내와 보정 반응 속도 개선**

  **상태: 보류** · 우선순위: P1

  - **할 일:** 분석 중·얼굴 없음·분석 실패를 구분하고 효과 미적용을 안내합니다. 동일 원본에서 슬라이더를 움직일 때 얼굴 분석과 인물 분할을 반복하지 않도록 재사용하고 사진 교체·해상도별 캐시 범위와 취소를 관리합니다.
  - **완료 조건:** 로딩 중 얼굴 없음 오안내 제거, 실패 시 재시도 가능, 이전 사진 결과 미혼입. 빠른 슬라이더 연속 입력 및 인물 조명+피부+배경 효과 조합의 지연·메모리·열 상태 측정과 개선 전후 비교.
  - **구현:** 얼굴 분석 대기/성공(0명 포함)/실패 분리 및 재시도. 동일 원본의 랜드마크·인물 마스크·화사한 필터 영역을 재사용하며 사진 교체 시 1개 원본 캐시 교체. 1600px 정규화 분석을 미리보기/출력에 공통 적용. 배경 분석 실패/인물 없음도 별도 안내. 단위 65개+UI 3개 통과, macOS 보조 검사 및 기기용 무서명 빌드 성공. [검증 기록](E2E.md#pf-033).
  - **남은 검증:** 실제 기기의 편집 지연·메모리·열 상태와 종합 효과 품질 수용은 미검증. 시뮬레이터 UI 검증 완료.
  - **추가 점검:** PF-027 시뮬레이터 테스트 결과에 내부 QoS 대기 경고가 기록되어 실제 편집 지연과 연관 여부를 확인합니다.
  - **선행 작업:** PF-027

  - **담당 / 갱신일:** Codex / 2026-10-02

- [ ] **PF-034 · 시뮬레이터·실기기 검증 분리와 실행 안정화**

  **상태: 보류** · 우선순위: P1

  - **할 일:** 시뮬레이터 이름+최신 OS 자동 선택 실패를 막고 명확한 장치 ID/런타임을 선택하도록 스크립트를 정리합니다. Vision 실기기 필수 검증과 시뮬레이터 대역/UI 테스트를 구분하고 사진 권한 복구 테스트 실패를 재현·수정합니다. macOS 피부 보정 검증 스크립트의 기존 변화량 기준도 현재의 절제된 보정에 맞는 영역·보존 기준으로 재설계합니다.
  - **완료 조건:** 지원하지 않는 추론을 조용히 통과시키지 않고 미지원/미실행을 보고. 시뮬레이터 필수 테스트·실기기 Vision/카메라 테스트 각각 결과 기록. 여러 런타임이 설치돼도 실행 대상이 일관되고 실제 권한 복구 실패 원인·수정 또는 재현 조건 기록.
  - **점검 기록:** PF-026에서 macOS 보조 스크립트의 오래된 함수 호출은 수정했으나, RGB 차이 8 초과 픽셀 1,000개 이상이라는 기존 기준에 대해 140개만 검출되어 실행 실패했습니다. 임계값을 임의로 낮추지 않고 평가 기준 보완으로 추적합니다.

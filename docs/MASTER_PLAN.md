# 전체 계획

기준일: 2026-09-09

## 목표와 현재 범위

아이폰용 사진 편집 앱의 구조와 할 일을 먼저 정리합니다. 문서 준비 후 기본 앱과 테스트 프로젝트 생성 단계로 진행했습니다. 기능 구현 순서와 실제 완료 상태는 [TASKS](TASKS.md)에서 관리합니다.

실제 아이폰이 없어도 다음 개발 단계에서 샘플 이미지와 시뮬레이터를 이용해 화면 및 정지 이미지 편집 흐름을 만들 수 있도록 설계합니다.

## 첫 시제품 제안

- 사진 한 장 또는 샘플 이미지 선택, 실제 기기에서는 편집기에서 카메라 촬영.
- 방향과 비율을 유지하는 미리보기.
- 원본·흑백·세피아·따뜻함·차가움에 더해 소프트 필름·골든아워·시네마틱·비비드 스타일과 강도 조절.
- 원본 비교와 초기화.
- 인물별 선택이 가능한 자연 피부 보정. 눈·입 등 얼굴 특징을 보존하고 강도와 복원을 조절.
- 결과를 별도 이미지로 내보내기.
- 불러오기, 처리, 저장, 실패 상태 안내.

핵심 가치는 인물 사진과 일상 사진에 의도적인 분위기를 더하되, 원본과 개인의 얼굴 특징에 대한 사용자의 통제권을 유지하는 것입니다. 모든 처리는 기기 안에서 수행합니다. 얼굴형 변경, 강제 미백, 생성형 이미지 편집, 계정·서버 전송은 이 범위에서 제외합니다. 첫 스타일 선택과 보정 상호작용의 결정 근거는 [DECISIONS](DECISIONS.md)의 PF-022를 참고합니다.

초기 버전·필터·출력 정책은 [DECISIONS](DECISIONS.md)의 PF-003 기준을 따릅니다. 로그인, 서버 전송, 결제는 초기 범위에서 제외하는 방향을 유지합니다.

## 화면의 모양

```text
시작 화면
┌────────────────────────┐
│ PictureFilterApp       │
│ 사진 선택 / 샘플로 시작 │
└────────────────────────┘
          ↓
편집 화면
┌────────────────────────┐
│ 사진 변경              │
│                        │
│    사진 미리보기       │
│                        │
│ 원본 비교              │
│ 원본 흑백 세피아 …     │
│ 강도 ──────●────       │
│ 초기화       저장      │
└────────────────────────┘
```

처리 중에는 상태 표시와 중복 저장 방지를 제공하고, 실패 시 재시도나 사진 변경을 안내합니다. 이는 화면 구성 초안이며 최종 디자인은 아닙니다.

## 단계와 완료 기준

| 단계 | 완료 기준 |
| --- | --- |
| 문서 준비 — 현재 | 구조, 할 일, 검증 범위가 연결됨 |
| 화면 시제품 — 후속 | 시뮬레이터에서 샘플로 선택·편집·결과 화면 이동 |
| 정지 이미지 MVP — 후속 | 실제 필터 연산과 파일 출력, 자동 테스트 및 시뮬레이터 검증 |
| 실제 아이폰 검증 — 개발자 모드 활성화 후 | 사진 선택·권한·사진 보관함 저장·메모리·성능 확인 |
| 카메라 및 얼굴 보정 — PF-021 | 촬영 이미지를 편집기로 전달하고 Vision 얼굴 랜드마크 기반 피부 보정 제공. 카메라는 실기기에서 확인 |

시뮬레이터 완료를 실제 아이폰 동작 보장이나 제품 출시 완료로 표현하지 않습니다.

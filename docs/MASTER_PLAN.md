# 전체 계획

기준일: 2026-09-26

## 최우선 제품 목표

**사진을 찍은 뒤 인물의 피부색과 얼굴 특징을 유지하면서 밝고 화사한 인물 사진으로 완성하는 앱**을 만듭니다. 기기가 현재 촬영 구성에서 제공하는 배율을 자유롭게 조절해 촬영하고, 결과에 인물 필터를 적용·조절·비교한 뒤 저장하는 흐름이 핵심입니다.

일반 색감 스타일과 배경 흐림은 이를 보조합니다. 배율은 기기·전후면 카메라·촬영 설정에 따라 달라지므로 고정된 0.5×·2×·5× 목록이나 Apple 기본 카메라와 동일한 최대 배율을 모든 기기에 약속하지 않습니다. 광학 렌즈 전환과 디지털 확대를 구분하고, 현재 사용 가능한 범위 안에서 연속 조절을 제공합니다.

구현 상태·우선순위·완료 여부는 [TASKS](TASKS.md)와 [보관소](TASKS_ARCHIVE.md)에서만 관리합니다. 이번 코드 점검 근거는 [DECISIONS](DECISIONS.md#review-20260926)에 있습니다.

## 사용 흐름

앱 시작 → 사진 촬영 또는 기존 사진 선택 → 전후면·지원 배율 선택과 촬영 → 인물 필터 결과 확인 → 강도·밝기·피부 질감 조절 → 원본 비교 → 별도 이미지 저장.

- 촬영과 사진 선택을 시작 화면에서 직접 실행합니다. 샘플은 보조 진입점으로 둡니다.
- 촬영 화면에는 실제 카메라 미리보기, 현재 배율, 지원 배율 바로가기, 핀치·연속 배율 조절, 전후면 전환, 초점·노출 조절, 셔터를 배치합니다.
- 촬영 후에는 화사한 인물 프리셋을 즉시 선택·비교할 수 있게 합니다. 재촬영 시 선택한 프리셋을 유지할 수 있도록 촬영 세션 설정과 사진별 보정을 구분합니다.
- 첫 목표는 촬영 후 정지 이미지 필터입니다. 카메라 화면의 실시간 필터는 이번 필수 범위에 추가하지 않습니다.

## 인물 필터 기준

첫 핵심 프리셋은 ‘화사한 인물’입니다. 얼굴 중간 밝기와 어두운 부분을 부드럽게 올리고 밝은 부분의 디테일을 보호하며, 조명에 따른 색 치우침을 완화합니다. 후속 후보는 자연스러운 피치 색감과 역광 인물 보정이며, 기본 프리셋의 품질을 먼저 검증합니다.

피부 보정은 선택 가능하고 약한 강도로 시작합니다. 피부 질감·눈·눈썹·입·수염·머리카락을 보존하며, 서로 다른 피부색을 동일하게 하얗게 만드는 방식은 사용하지 않습니다. 원본 비교·강도 0·전체 및 인물별 복구를 제공합니다. 얼굴형 변경·생성형 얼굴 편집·사진 서버 전송은 범위 밖입니다.

## 구현 순서와 완료 기준

1. 여러 인물의 보정값 유지와 개별 원본 복구를 바로잡습니다.
2. 화사한 인물 필터와 피부색·하이라이트 보호 기준을 구현합니다.
3. 전용 카메라와 기기별 배율 조절을 구현합니다.
4. 촬영 → 필터 → 재촬영·저장 흐름을 연결합니다.
5. 실제 촬영 사진과 다양한 조명·피부색에서 결과, 배율, 방향, 저장 품질을 검증합니다.

마스크 경계·미리보기와 출력의 일관성·반응 속도·테스트 안정성 개선을 함께 추적합니다. 합성 이미지 픽셀 테스트 통과만으로 자연 인물 사진의 화사함이나 촬영 품질을 완료로 판정하지 않습니다.

현재 출력 정책(JPEG 0.9, sRGB/SDR, 긴 변 최대 4096px, 위치 등 메타데이터 제외)은 유지하되, 고해상도 촬영 입력과 최종 출력 한도를 구분합니다. 원본 해상도 내보내기는 별도 범위 결정 전까지 약속하지 않습니다.

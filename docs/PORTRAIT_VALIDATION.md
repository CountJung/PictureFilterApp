# 화사한 인물 필터 품질 검증표 · PF-035

PF-027 구현 완료 후 남은 실제 사진 검증을 보관합니다. 상위 작업 상태는 [PF-035](TASKS.md#pf-035), 기존 구현·시뮬레이터 결과는 [E2E](E2E.md#pf-027)를 참고합니다. 이 문서의 체크박스는 **검증 실행 단위**이며 각 번호를 지정해 리뷰할 수 있습니다. 현재 모두 미실행입니다.

## 공통 준비 및 판정

촬영·편집 동의를 받은 사진 또는 사용 조건이 확인된 공개 사진만 사용합니다. 개인 사진은 Git에 넣지 않고 `private-samples/`에 두며 기록에는 식별번호만 씁니다. 원본 파일은 수정하지 않습니다. 모든 결과에는 커밋·기기·OS·입력 크기·조명 조건·실제 얼굴 검출/대역 여부·출력 크기를 기록합니다. 저장 위치에는 개인 이름과 위치 정보를 적지 않습니다.

기본 비교는 **원본 / 프리셋 강도 0 / 기본 0.5 / 최대 1.0** 네 장입니다. 기본 밝기 0.65·따뜻함 0.15, 피부 질감·추가 인물 조명·배경 흐림 0에서 시작합니다. 별도 효과는 기본 프리셋 평가 뒤 하나씩 조합합니다. 같은 표시 크기와 100% 확대에서 비교하고 화면 밝기·True Tone·Night Shift 설정을 기록해 비교 도중 바꾸지 않습니다.

검증 시작 전에 사진별 얼굴·밝은 피부·흰옷·배경의 비교 영역을 정합니다. 숫자는 아래의 **초기 수용 기준**이며 아직 검증된 품질 보장이 아닙니다. 기준 변경 시 이유와 이전 판정을 남기고 같은 자료 전체를 다시 판정합니다. 새로 생긴 클리핑은 원본에서 250 미만이던 영역이 결과에서 254 이상으로 올라간 RGB 채널 비율로 기록하며, 원래 날아간 하이라이트는 별도 집계합니다.

- 기본 강도에서 어두운 얼굴 영역의 8비트 가중 밝기(0.2126R + 0.7152G + 0.0722B) 평균이 2 이상 증가해야 합니다. 충분히 밝은 얼굴은 증가량 대신 하이라이트·색감 보존을 우선합니다.
- 피부/흰옷 ROI의 새 클리핑 증가율이 0.5%p를 넘으면 실패 후보로 분류하고 확대 리뷰합니다. 원본에 있던 디테일이 사라지면 증가율과 관계없이 실패입니다.
- 육안 판정은 밝기 개선·피부색 자연스러움·질감·경계 각각 `합격/수정 필요/판정 불가`로 남깁니다. 얼굴 형태 변화, 눈·입 디테일 손실, 뚜렷한 헤일로는 실패입니다. 숫자만으로 자연스러움 합격을 대신하지 않습니다.

## 세부 실행 항목

- [ ] **PF-035-01 · 대표 자료 선정과 기준 확정**

  실내 혼합광·야외 그늘·야외 직사광·창가 역광·저조도 각 2장 이상을 선정합니다(최소 10장). 전체 자료에서 밝은/중간/어두운 피부색, 흰옷, 수염, 안경, 옆얼굴, 다중 인물을 포함합니다. 조건이 겹쳐도 되지만 빠진 조건은 명시합니다. 사진별 허가/출처·조명·피부색 범위·관심 영역·노출 부족/과다 여부를 기록하고 비교 기준을 확정합니다. 합성 자료와 촬영 환경 불명의 공개 사진은 보조 자료로 분리합니다.

- [ ] **PF-035-02 · 기본값의 밝고 화사한 결과**

  각 대표 사진을 원본/0/0.5/1.0으로 렌더합니다. 실내 색번짐·역광 그림자·저조도 노이즈가 악화되는지 확인합니다. 기본값만으로 얼굴의 어두운 부분이 개선되는지 밝기 ROI와 전후 육안 리뷰를 기록합니다. 보정으로 살릴 수 없는 원래 클리핑/심한 노이즈는 개선 실패와 구분해 한계를 적습니다. 실패 사진을 삭제해서 합격률을 높이지 않습니다.

- [ ] **PF-035-03 · 피부색·하이라이트·색 균형**

  밝은/중간/어두운 피부색 및 흰옷 자료에서 기본/최대 강도의 피부색 치우침과 새 클리핑을 비교합니다. 따뜻함 -1/0/0.15/1, 밝기 0/0.65/1 극단 조합을 추가하고 밝은 부분이 노랗거나 붉게 물들지 않는지 확인합니다. 원본의 피부색 정체성과 밝은 옷의 질감이 유지되어야 합니다. 실패 시 사진 ID·ROI·설정·픽셀 비율·전후 확대 이미지를 남깁니다.

- [ ] **PF-035-04 · 질감·특징·얼굴 경계**

  피부 모공·잔주름·수염·머리카락·안경·눈·입을 100% 확대합니다. 프리셋 단독과 피부 보정 0.3/1.0 조합을 나눠 비교합니다. 옆얼굴·가림·다중 인물에서 타원 보정의 배경 누출/헤일로 및 인물 간 밝기 불균형을 확인합니다. 강도 변경으로 얼굴 형태나 눈·입 위치가 바뀌지 않아야 합니다. 경계 문제는 PF-032, 분석 실패/지연 문제는 PF-033과 연결합니다.

- [ ] **PF-035-05 · 실제 얼굴 분석과 미검출 대안**

  실제 iPhone에서 얼굴 수 0/1/여러 명, 작은 얼굴, 옆얼굴, 가림을 검사합니다. 얼굴 검출 성공 여부와 프리셋 결과를 함께 기록합니다. 미검출/분석 실패에서는 전체 톤 보정만 적용되고 앱이 멈추거나 빈 결과를 저장하지 않아야 합니다. 시뮬레이터 고정 좌표 테스트를 실제 검출 근거로 쓰지 않습니다. 개별 피부·조명 A/B 설정도 보존되는지 확인합니다.

- [ ] **PF-035-06 · 원본·미리보기·저장 일관성**

  동일 사진의 1600px 미리보기와 4096px JPEG를 같은 표시 크기로 비교합니다. 실제 얼굴 검출 영역과 경계가 달라지지 않는지 확인하고 방향 메타데이터가 다른 세로/가로 입력을 포함합니다. 평탄한 얼굴/배경 ROI의 채널 평균 차이 3 이내를 초기 기준으로 하되 JPEG 압축·축소 차이는 별도 기록합니다. 강도 0·원본 누름 비교·전체 초기화·사진 교체 후 원본 보존과 설정 리셋을 확인합니다. 사진 보관함 저장 후 다시 열어 색감·방향·해상도를 확인합니다.

- [ ] **PF-035-07 · 사용자 리뷰와 수용 결정**

  대표 자료의 원본/기본/최대 비교표를 사용자가 검토하고 사진별 선호·수정 필요·판정 불가를 기록합니다. 모든 필수 조건에 합격 근거가 있고 실패 사항의 수정/재검증이 끝나면 PF-035를 완료 처리합니다. 피치·역광 추가 프리셋 필요성은 이 결과로 결정하며, 실제 카메라·배율·재촬영까지의 통합 수용은 PF-031에서 진행합니다.
